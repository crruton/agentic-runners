# CI-шаблон для агентной разработки

`agentic-ci.yml` даёт проекту две вещи из ADR-0006:

- **H1** — пайплайн снимается на первом упавшем задании (`auto_cancel: on_job_failure: all`), а внутри тестового задания сессия останавливается на первом упавшем тесте, прошлые падения идут первыми (`--rt-fail-fast`). Оценка по истории — 13,8% часов раннеров (E06).
- **H10** — на MR выполняются только затронутые тесты (`--rt-select=coverage`, E09), полный набор — один раз в поезде слияния и на основной ветке. Оценка — до 35,9% часов (E06); коммиту агента нужно в среднем 45,5% тестового времени даже при выборе по импортам (E08).

Полный набор в поезде и на основной ветке идёт без кэша результатов: решение «что пропустить» никогда не принимается на проверке перед слиянием.

## Подключение

Шаблон рассчитан на merge trains (Settings → Merge requests → Merge trains). Без них полный набор выполняется только на основной ветке после слияния.

```yaml
include:
  - project: architects/agentic-runners
    ref: main
    file: ci-templates/agentic-ci.yml

lint:
  stage: test
  script: [ruff check .]

tests:mr:
  extends: .agentic-mr-tests
  script: [pytest]

tests:full:
  extends: .agentic-full-tests
  script: [pytest]
```

Проект с собственными `workflow:rules` объединяет их с `workflow:auto_cancel` из шаблона вручную: `workflow` из include и из проекта не сливаются по ключам правил.

Если тестовая команда уже передаёт `-n` (pytest-xdist), рантайм не включает свои воркеры-форки и работает поверх xdist: кэш, порядок и остановка на первой ошибке сохраняются.

## Откат

Убрать `include` и `extends`. Кэш `.rt-cache/` влияет только на MR-задания.
