# Spec Delta

## Purpose

Связывает цифры в документах и на слайдах с показателями отчёта, чтобы ни одно число не появлялось в докладе мимо данных.

## ADDED Requirements

### Requirement: Таблица цифр генерируется
Команда `runners numbers` SHALL генерировать `docs/talk/numbers.md` из `out/metrics.json`: каждый показатель с подписью, значением, источником, периодом и id.

#### Scenario: Повторная генерация
- **WHEN** `runners numbers` запущен дважды на одном metrics.json
- **THEN** файл не меняется

### Requirement: Проверка ссылок
Команда `runners check` MUST завершаться с ненулевым кодом, если в `docs/**/*.md` есть ссылка на id показателя, которого нет в `metrics.json`, или если `docs/talk/numbers.md` устарел.

#### Scenario: Ссылка на несуществующий показатель
- **WHEN** документ ссылается на `queue.p97_s`
- **THEN** `runners check` печатает файл и строку и возвращает 1

### Requirement: Весь офлайн-процесс одной командой
Команда `runners all` SHALL последовательно строить отчёт, генерировать таблицу цифр и выполнять проверку.

#### Scenario: Чистое дерево
- **WHEN** снимок есть и документы ссылаются только на существующие показатели
- **THEN** `runners all` возвращает 0
