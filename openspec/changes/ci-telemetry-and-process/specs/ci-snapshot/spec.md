# Spec Delta

## ADDED Requirements

### Requirement: Источник пайплайна
Снимок SHALL содержать `gitlab_pipelines.csv.gz`: идентификатор, проект, ветку, источник (`push`, `merge_request_event`, `schedule`, `api`, `web`), статус и время создания каждого пайплайна за окно выгрузки.

#### Scenario: Покрытие заданий
- **WHEN** снимок содержит и задания, и пайплайны GitLab за одно окно
- **THEN** для каждого задания известен источник его пайплайна

### Requirement: Ресурсы задания из логов
Снимок SHALL содержать `job_resources.csv.gz` с разобранными показателями cgroup v2 задания (cpuset, `memory.max`, `memory.peak`, `oom_kill`, своп и PSI памяти хоста) для шардов santinel. Сырой текст логов MUST NOT сохраняться.

#### Scenario: Только числа
- **WHEN** лог задания содержит строки `job-resources:`
- **THEN** в снимке есть только разобранные поля, без строк лога

#### Scenario: Незнакомый формат
- **WHEN** в логе нет ожидаемых строк
- **THEN** запись получает `parsed=0`, выгрузка продолжается
