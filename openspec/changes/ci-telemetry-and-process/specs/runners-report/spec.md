# Spec Delta

## ADDED Requirements

### Requirement: Replay учитывает источник пайплайна
Когда в снимке есть источники пайплайнов, replay политики `interruptible` MUST строить цепочку вытеснения только из пайплайнов `push` и `merge_request_event`.

#### Scenario: Расписание на main
- **WHEN** после пайплайна пуша на `main` создан пайплайн по расписанию
- **THEN** пайплайн пуша не считается вытесненным

### Requirement: Раздел ресурсов задания
Отчёт SHALL содержать раздел «Ресурсы задания: cgroup v2»: долю заданий, упёршихся в `memory.max`, долю заданий с OOM-kill внутри cgroup, CPU хоста против cpuset задания и длительность по лимиту памяти.

#### Scenario: Нет телеметрии
- **WHEN** в снимке нет `job_resources.csv.gz`
- **THEN** раздел помечен «Нет данных в снимке»
