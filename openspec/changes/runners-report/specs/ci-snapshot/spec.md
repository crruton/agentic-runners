# Spec Delta

## Purpose

Снимает данные CI (БД аналитики раннеров и историю заданий GitLab) за один заход в локальный каталог, чтобы весь анализ шёл без постоянного сетевого доступа.

## ADDED Requirements

### Requirement: Снимок за один запуск
Команда `runners snapshot` SHALL за один запуск выгрузить все таблицы и представления схемы `public` БД `ci_analytics` и задания GitLab за заданное число дней в `data/snapshots/<YYYYMMDD>/`.

#### Scenario: Успешный снимок
- **WHEN** заданы `CI_ANALYTICS_DSN` и `GITLAB_TOKEN`, источники доступны
- **THEN** в каталоге снимка есть по файлу `ci_analytics/<таблица>.jsonl.gz` на каждую таблицу и представление, файл `gitlab_jobs.csv.gz` и `manifest.json`

#### Scenario: Только один источник
- **WHEN** запуск идёт с `--only ci_analytics` или `--only gitlab`
- **THEN** выгружается только этот источник, записи манифеста о других источниках того же дня не меняются

### Requirement: Манифест снимка
Снимок MUST содержать `manifest.json` с временем снятия (UTC), числом строк по каждой таблице, параметрами выгрузки GitLab (дни, число проектов) и статусом каждого источника.

#### Scenario: Сверка полноты
- **WHEN** снимок завершён
- **THEN** число строк каждого файла совпадает с числом в манифесте

### Requirement: Отказоустойчивость при обрыве сети
Если источник недоступен или соединение оборвалось, команда MUST завершиться с ненулевым кодом, записать в манифест статус `failed` для этого источника и не оставлять частичный файл под итоговым именем.

#### Scenario: Обрыв VPN во время выгрузки
- **WHEN** соединение с БД обрывается на середине таблицы
- **THEN** файл этой таблицы не появляется под итоговым именем, манифест отмечает источник `failed`, код выхода не 0

### Requirement: Секреты не попадают в снимок
Строки подключения, пароли и токены MUST NOT записываться в файлы снимка, манифест и вывод команды.

#### Scenario: Проверка манифеста
- **WHEN** снимок снят с DSN, содержащим пароль
- **THEN** ни в одном файле каталога снимка и в выводе нет пароля и токена

### Requirement: Только чтение
Команда MUST открывать соединение с БД в режиме только чтения и MUST NOT выполнять запросы, изменяющие данные GitLab.

#### Scenario: Режим соединения
- **WHEN** открыто соединение с `ci_analytics`
- **THEN** сессия помечена как read-only
