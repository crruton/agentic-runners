# Spec Delta

## Purpose

Даёт воспроизводимую оценку гипотез о CI агентов по истории снимка, чтобы порядок внедрения выбирался по данным.

## ADDED Requirements

### Requirement: Оценка по правилу
Для каждой гипотезы отчёт SHALL показывать сэкономленные часы, долю от всех часов источника, источник и риск, рассчитанные по правилу, описанному в коде.

#### Scenario: Остановка на первой ошибке
- **WHEN** в пайплайне задание упало на 10-й минуте, другое стартовало на 12-й и шло 20 минут, третье шло с 5-й по 25-ю
- **THEN** H1 засчитывает 35 минут

#### Scenario: allow_failure
- **WHEN** упало только задание с `allow_failure`
- **THEN** H1 не считает пайплайн упавшим

### Requirement: Честный знак
Оценка MUST NOT обрезаться до нуля: если вариант дороже текущего, показывается отрицательное значение.

#### Scenario: Пакетирование при частых падениях
- **WHEN** почти каждая пачка пайплайнов содержит падение
- **THEN** H12 показывает отрицательную экономию
