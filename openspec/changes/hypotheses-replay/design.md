# Design

## Decisions

1. Одна функция на гипотезу, правило — в docstring, тест на правило — синтетические задания.
2. Падения с `allow_failure` не считаются падениями (флаг из БД, для GitLab — по join с БД).
3. Отрицательная оценка показывается как есть: «дороже» — тоже результат.
4. Раздел требует заданий GitLab, источников пайплайнов и заданий БД; без них — «нет данных».
