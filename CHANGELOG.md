# Changelog

## [Unreleased]

### Added

- План проекта, заявка на RULKC Conf 2026, разбор Scion, ADR-0001, каркас OpenSpec.
- Сбор базовой линии: `collect/ci_history.py` (GitLab API), `collect/baseline.py`, `collect/ci_analytics.py` (БД аналитики раннеров).
- E00: базовая линия CI за 30 дней и тренд по неделям (`docs/experiments/E00-*`).
- Пакет `runners`: `python -m runners snapshot` (разовый снимок БД и GitLab без ПДн), `report` (офлайн-отчёт `out/report.html` и `out/metrics.json`), `import-legacy`. Тесты в `tests/`.
- OpenSpec change `runners-report`: спецификации `ci-snapshot` и `runners-report`.
- `runners/whatif.py`: оценка `interruptible` повторным прогоном истории без изменений в репозиториях, модель очереди (E01).
- `docs/research/inventory.md`, `docs/research/fleet.csv`: парк 4 → 22 регистрации за 2 месяца.
- Источники снимка `gitlab_pipelines` (источник пайплайна) и `job_resources` (cgroup v2 задания из логов шардов santinel, только разобранные числа).
- Раздел отчёта «Ресурсы задания: cgroup v2» и E02: естественный эксперимент по классам хостов (8 ядер / 15 GiB против 12 ядер / 31 GiB).
- Команды `runners numbers`, `check`, `all`; `docs/talk/numbers.md`, `docs/process.md`, `docs/research/santinel-ci.md`.
- `runners bench` (с `--resume`): A/B конфигураций ноутбука-раннера на эмулированном хосте (cgroup v2 в Docker Desktop), эмулятор шарда `bench/`, раздел отчёта «Эмуляция A/B», E03.
- ADR-0002 (replay вместо правок в репозиториях), ADR-0003 (телеметрия из логов заданий), ADR-0004 (эмуляция вместо боевого A/B).
- Тестовый рантайм `runtime/agentic_runtime`: воркеры форком от прогретого процесса с `gc.freeze()`, перезапуск упавшего воркера, кэш результатов по хэшу входов, телеметрия `job-resources:`; демо и E04 (память −31…−59%, время −16…−44%, повторный прогон без изменений — только сбор тестов).
- Рантайм: запись выполненного кода через `sys.monitoring` на Python 3.12+ (около +8…13% вместо +40% у `setprofile`), откат на `setprofile`, если идентификатор инструмента занят.
- `handover/ansible-runners.md`: пакет для администратора раннеров — бюджет памяти слотов с учётом числа сервисов (service_memory 1g на 16-гигабайтных хостах, с проверкой на notebook-runner-5), buran в пул, nvme-runner из пула тяжёлых тестов.
- CI-шаблон `ci-templates/agentic-ci.yml` (H1, H10): снятие пайплайна на первом упавшем задании, на MR — затронутые тесты рантаймом, полный набор — в поезде слияния и на основной ветке без кэша результатов.
- Рантайм уступает параллелизм pytest-xdist (`-n` и воркеры xdist), сохраняя кэш, порядок и остановку на ошибке.
- `runners pilot` и `docs/pilot/ci-preflight-pilot.md`: базовая линия и критерии пилота ci-preflight; 11.11 скилл поставлен агентам на машине владельца, главный проект пилота — project-estimator (к lad нет доступа).
- Рантайм: `--rt-select=coverage` — ключ кэша по выполненному коду и коду фикстур setup, обходит связность через корневой conftest (H4, E09).
- `runners affected` и E08: по истории santinel коммиту агента нужно в среднем 45,5% тестового времени (H4); корневой conftest связывает 514 из 521 модуля приложения.
- Скилл `skills/ci-preflight` (H2, H11, H3/H8): окружение на задачу, линт и затронутые тесты до пуша, пуш только зелёного, бюджет красных пайплайнов; рантайм упакован (`runtime/pyproject.toml`, `agentic-runtime` 0.2.0).
- Рантайм: `--rt-fail-fast` — остановка на первом упавшем тесте, прошлые падения первыми (H1, E07); исправлен двойной `waitpid` при остановке в режиме форка.
- `runners/hypotheses.py` и раздел отчёта «Гипотезы»: офлайн-оценка H1, H2, H3, H10, H12, H13 (E06); сценарий эмуляции P-psi для H6; ADR-0006 — порядок внедрения.
- E05: поведение агентов в CI по свежему снимку 20261110 (50% часов в красных пайплайнах, 15,9% после первого падения, серии до 23 красных подряд, 30,6% часов ночью); `docs/research/agentic-ci-hypotheses.md` — гипотезы с источниками и планом проверки; обзор подходов на GitHub и гипотезы H9–H13.
- `docs/research/runner-iac.md`: устройство раннеров по их Ansible-конфигу.
- ADR-0005: раннеры разгружаем тестовым рантаймом платформы; OpenSpec change `test-runtime`.
- Инвентаризация: эталон ноутбука-раннера (Core Ultra 5 125U, 12 ядер, 39 GiB), сервер `buran` с RTX 4090 вне пула тестов, права на теги раннеров — только у администратора.

### Changed

- E02: причина OOM хоста подтверждена Ansible-конфигом раннеров — переподписка памяти (слот santinel 8 GiB, два слота на хосте с 15 GiB); `docs/research/runner-iac.md`.

- Рост в отчёте считается за 2 месяца по полным неделям с усреднением краёв (×3,4 заданий, ×4,9 часов).
- E00: отмены до старта считаются только по GitLab; все запуски CI — через агентов.

### Fixed

- E00: рост больше не считается от неполной первой недели (было ×7,4 / ×16,7 — завышено).
- E01: replay учитывает источник пайплайна; оценка `interruptible` 5,7% вместо завышенных 13,1% (пайплайны по расписанию на main ошибочно считались вытесняемыми).
- CHANGELOG: записи, ошибочно попавшие в раздел Removed, перенесены в Added.
- E03: прогон в неравных условиях по диску отбракован, все сценарии повторены (`20261109-2358`); вывод «C быстрее на 39%» был артефактом.
- Бенч удаляет скачанные им образы и, если кэш сборки до прогона был пуст, кэш сборки.

### Removed

- `bench/compact-docker-disk.ps1`: диск сжат напрямую, отдельный скрипт не нужен.

- `collect/snapshot.py`: логика перенесена в `runners/snapshot.py`.
